# EROPULSE AI

Hyper-masculine uncensored gay erotica AI prompt generator.

Built with Next.js 15, Tailwind, Framer Motion.

## Features
- Real-time PBE (Prompt Builder Engine)
- Kink selector with leather style
- Intensity slider
- Freemium monetization (Pulse & Alpha tiers)
- Simulated hyper-realistic previews

## Quick Start
```bash
git clone https://github.com/kwizzlesurp10-ctrl/eropulse-ai.git
cd eropulse-ai
npm install
npm run dev
```

Deploy on Vercel with one click.
